# jewaixp-client — ICQ-клиент под Windows XP для JewAI

Внешний модуль для проекта **[JewAI](https://github.com/PaaLadin/jewai)**.
Позволяет командовать агентами JewAI с Windows XP.

Клиент восстанавливает идею классического ICQ 99b: список
контактов, отдельные окна диалогов, статусные иконки-цветочки,
звуки и мигание непрочитанного.

Оригинальный проект JewAI: **https://github.com/PaaLadin/jewai**
Полная архитектура, mainframe, агенты, RAG — там.

---

## Зачем нужен этот клиент

JewAI работает через расширение браузера. На Windows XP стоит
Chrome 49 — последний браузер, выпускавшийся для этой системы.
Он не рендерит современный фронтенд `chat.deepseek.com`.

Решение — тонкий клиент. XP не рендерит ничего тяжёлого,
только свой tkinter-интерфейс. Вся работа идёт на машине с JewAI.
Обмен — по HTTP+JSON с mainframe (порт 8770).

```
Windows XP                          Windows 10
┌────────────────────┐              ┌────────────────────┐
│ jewaixp-client     │              │ JewAI mainframe    │
│ (ICQ-интерфейс)    │  HTTP+JSON   │ 8770               │
│ Python 3.4 tkinter │ ──────────►  │  + агенты          │
│                    │ ◄──────────  │  + браузер         │
└────────────────────┘              │  + RAG             │
                                    └────────────────────┘
```

XP остаётся в игре. Просто роль меняется: из «рабочей станции»
он становится «терминалом».

## Что внутри

- `xp_client.py` — точка входа.
- `api.py` — HTTP-клиент к mainframe.
- `state.py` — локальный лог непрочитанного.
- `icons.py` — загрузчик иконок.
- `sound.py` — звуки (winsound).
- `ui_main.py` — главное окно (список каналов).
- `ui_chat.py` — окно диалога + History + Bash.
- `1_install_python.bat` — установка Python 3.4.4.
- `2_setup_and_run.bat` — wizard + запуск.
- `setup_client.py` — интерактивная настройка.
- `xp_client.example.json` — образец конфига.
- `run_client.bat` — launcher.
- `icq_*.gif` — иконки цветка.
- `sounds/` — WAV-звуки из ICQ 99b.

## Требования

- Windows XP SP3 (или новее).
- Python 3.4.4 — последний, поддерживающий XP.
- Доступ к mainframe JewAI по сети (порт 8770).
- Запущенный mainframe JewAI на другой машине.

## Установка

### 1. Скачать Python 3.4.4

Прямая ссылка:

    https://www.python.org/ftp/python/3.4.4/python-3.4.4.msi

Положить этот файл рядом с `1_install_python.bat`.

### 2. Скопировать папку

Скопировать содержимое репозитория на XP, например в
`C:\jewaixp-client\`.

### 3. Установить Python

Правый клик на `1_install_python.bat` → «Запуск от имени…»
(нужны права администратора).

Дождаться сообщения `[ OK ] installed`.

Открыть новое cmd — PATH подхватится автоматически.

Проверить:

    C:\Python34\python.exe --version

Ожидаемый вывод: `Python 3.4.4`.

### 4. Настроить и запустить

Двойной клик по `2_setup_and_run.bat`.

Wizard спросит:
- **Mainframe URL** — адрес машины с JewAI. Пример:
  `http://192.168.1.24:8770`.
- **Your nick** — как подписываются твои сообщения.

После ответа wizard сохранит `xp_client.json`, проверит связь
с mainframe и запустит клиент.

## Как работать

Главное окно — список каналов:
- «Общий» — общий чат всех агентов.
- «Аркадий», «Борис», «Семён», «Димон» — персональные каналы.

Двойной клик по имени открывает окно чата.

Кнопки главного окна:
- **COUNCIL** — режим совещания.
- **PAUSE** — полная пауза всем.
- **RESUME** — снять паузу.
- **Logs** — открыть серверный лог общего чата.

В статус-баре: состояние соединения, справа — счётчик
`cmds_from_start` (порог перерождения агента 850+).

В окне чата:
- **History** — открыть полную историю канала.
- **Bash** — анимированный смайлик + метка `:bash:`.
- **Send** / **Cancel** — отправить / закрыть.

## Звуки

Клиент играет классические звуки ICQ 99b:

- **запуск** — при старте клиента.
- **входящее** — при новом непрочитанном сообщении.
- **набор** — на каждое нажатие клавиши в поле ввода.
- **отправка** — при успешной отправке.

Файлы лежат в `sounds/`: `Startup.wav`, `Message.wav`,
`MsgType.wav`, `MsgSent.wav`. Плюс запасные: `Global.wav`, `Online.wav`,
`Notify.wav` — пока не задействованы.

Выключить: **File → Sound on/off**.

---

## Иконки

Иконка — цветок ICQ:
- **зелёный** — агент онлайн.
- **серый** — агент офлайн.
- **мигает с красным лепестком** — непрочитанное.

Имя агента **жирным** — если непрочитанное и агент онлайн.

## Совместимость с Python 3.4

Клиент написан строго под Python 3.4.4. Это ограничение XP.
Из кода сознательно исключены:

- f-строки (Python 3.6+).
- `async` / `await` (3.5+).
- `subprocess.run` (3.5+).
- `secrets` (3.6+).
- `ThreadingHTTPServer` (3.7+).
- `Path.write_text(encoding=)` (3.5+).

В Tkinter используется только `PhotoImage` (GIF и PPM). PNG не
поддерживается.
