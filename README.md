# JewAIXP client — ICQ-стиль для Windows XP

Тонкий клиент под Windows XP (Python 3.4 + tkinter).
Работает с council_chat (mainframe, порт 8770) по HTTP+JSON.

Интерфейс — клон ICQ 99b:
- главное окно со списком каналов и иконками-цветочками,
- отдельные окна диалогов на каждый канал,
- статус-бар с состоянием соединения,
- встроенная история (серверный лог),
- кнопка «Bash» с анимированным смайликом.

## Зачем нужен клиент

Chrome 49 (последний под XP) не рендерит современный фронтенд
DeepSeek. Поэтому XP не может использовать расширение напрямую.
Клиент превращает XP в тонкий терминал: ты пишешь задачу в
ICQ-подобное окно, mainframe доставляет её агенту на Win10,
ответ возвращается в клиент.

Тяжёлая работа (LLM, браузер, файловая работа) — на Win10.

## Что внутри

- `xp_client.py` — точка входа.
- `api.py` — HTTP-клиент к mainframe.
- `state.py` — локальный лог непрочитанного.
- `icons.py` — загрузчик иконок (GIF, три варианта).
- `ui_main.py` — главное окно (список каналов).
- `ui_chat.py` — окно диалога, история, анимация «Bash».
- `xp_client.example.json` — образец конфига.
- `run_client.bat` — launcher.
- `icq_*.gif` — иконки трёх видов: online / new / offline,
  каждый в размере 8, 16 и 32.

## Требования

- Windows XP SP3 (или новее).
- Python 3.4.4 (последний под XP).
- Доступ к mainframe по сети (обычно порт 8770 на машине Win10).

## Настройка

1. Скопировать папку на XP, например в `C:\jewai\client\`.
2. Установить Python 3.4.4 (msi с python.org, XP-версия).
3. Переименовать `xp_client.example.json` в `xp_client.json`.
4. Открыть `xp_client.json` блокнотом. Указать:
   - `server` — URL mainframe. Пример: `http://192.168.1.24:8770`
     (где 192.168.1.24 — IP машины с mainframe).
   - `nick` — как подписываются твои сообщения в чате.
     По умолчанию `operator`.
   - `poll_ms` — частота опроса сервера (мс). 4000 = раз в 4 сек.
   - `font_size` — размер шрифта в окне.
5. Сохранить файл.

## Запуск

Двойной клик по `run_client.bat`. Откроется главное окно
`JewAIXP` со списком каналов.

## Что проверять при первом запуске

- **Статус-бар внизу** — `Connected` (значит mainframe отвечает)
  или `Disconnected` (нет связи, проверь адрес и файрвол).
- **Список каналов**: «Общий», «Аркадий», «Борис», «Семён», «Димон».
- **Иконки**:
  - зелёный цветок — агент онлайн,
  - серый — офлайн,
  - с красным лепестком (мигает) — есть непрочитанное.
- **Двойной клик** по имени — открыть окно чата.
- **Имя жирным** — есть непрочитанное от онлайн-агента.

## В окне чата

- Верх — `To: <порт> | Nick: <имя> | From: <твой ник>`.
- Середина — история сообщений (только она масштабируется).
- Низ — поле ввода, кнопки `History`, `Bash`, `Send`, `Cancel`.

Кнопки:
- **History** — открыть окно с полным логом канала с сервера.
- **Bash** — анимация смайлика + вставка метки `:bash:` в текст.
- **Send** — отправить (то же, что Ctrl+Enter).
- **Cancel** — закрыть окно.

## Известные ограничения

- Только Windows XP / Python 3.4.
- Нет вложения файлов.
- Нет шифрования канала (только локальная сеть).
- Red GIF (все лепестки красные) подготовлен, но пока не
  используется в интерфейсе — лежит «на будущее».

## Безопасность

- Секретов в клиенте нет.
- Токены и логины mainframe **не хранятся** в файлах клиента.
- Авторизация — на стороне mainframe (по IP или явному ACL).
- Если mainframe требует токен доступа — положить его в
  `xp_client.json` не поддерживается. В данной версии клиент
  работает в режиме «локальной сети без аутентификации».
