# Changelog — jewaixp-client

Все заметные изменения проекта.

## [1.0.0] — 2026-10-11

### Добавлено

- Первый публичный релиз.
- ICQ-стиль: главное окно со списком каналов, отдельные окна
  диалогов на каждый канал.
- Иконки — цветок ICQ в трёх вариантах: online (зелёный),
  new (красный лепесток, мигает), offline (серый).
- Мигание непрочитанного, жирный шрифт для непрочитанного
  от онлайн-агента.
- Общий и персональные каналы, двусторонний обмен.
- Кнопка History — открывает серверный лог канала.
- Кнопка Bash — анимированный смайлик + метка `:bash:`.
- Кнопки управления повесткой: COUNCIL, PAUSE, RESUME.
- Кнопка Logs — общий лог с сервера.
- Индикатор `cmds_from_start` в статус-баре.

### Ограничения

- Только Windows XP + Python 3.4.4.
- Требует работающего mainframe JewAI (порт 8770).
- Нет вложений, нет шифрования.
- Только локальная сеть.

### Техническое

- Совместимость Python 3.4: без f-строк, без async/await,
  без subprocess.run, без secrets, без ThreadingHTTPServer.
- Tkinter PhotoImage: только GIF и PPM.
- Работает с Chrome 49 (последний браузер под XP).
